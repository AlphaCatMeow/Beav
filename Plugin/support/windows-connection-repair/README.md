# Windows 浏览器连接修复包

适用于本次插件 2.7.16 持续无法连接的支持排查。无需管理员权限，不需要重装插件或等待新版 App。

1. 保持 Beav 打开，把压缩包完整解压。
2. 双击 `Run-Repair.cmd`。使用当前运行的 Beav；存在多个版本时会让你选择程序文件。
3. 完成后在 Edge 扩展管理页重新加载 Beav 插件，打开弹窗检查连接。

工具直接测试 Native Host 握手，备份当前用户注册并调用 Beav 自带安装命令重新注册。不会关闭用户的 App、修改浏览器策略、清理用户数据或安装其他程序。启动的临时自检 Host 会在结束后关闭。脚本启动器仅对本次 PowerShell 进程设置 ExecutionPolicy，不永久修改系统执行策略；如果系统安全策略阻止脚本，不要求关闭防护。

脱敏的程序路径/版本/哈希、注册结果、握手错误和最近 Host 启动/协议错误会自动发送到 Beav 反馈后台，并关联本次工单。原始注册备份仅保存在桌面 `Beav-连接诊断-*` 目录；不上传浏览器资料、网页内容、Cookie、桥接凭证或完整应用日志。发送失败时保留本地诊断文件。

Host 握手通过仅证明直接启动可用，Edge 是否恢复需以插件弹窗为准。此工具不能修复损坏的安装文件或解除系统拦截；失败时自动上传证据，便于支持继续处理。
